# Team Utopia

## Project Name
GatePass — QR-Based Event Check-In

## Problem Statement
Event organizers often manage registrations and entry manually, which can be slow and prone to errors. Build a web application that lets organizers register attendees, issue unique QR passes, and verify entry at an event.

## Our Solution
## 💡 Proposed Solution

**GatePass** is a web-based event registration and attendance management system designed to simplify and automate the event check-in process using QR code technology.

Our solution replaces traditional manual attendance verification with a faster, more efficient, and reliable digital system.

###  How Our Solution Works

1. **Attendee Registration:** Participants register for an event through a simple web interface. Their details are securely stored in a centralized database.

2. **Unique QR Pass Generation:** Each registered attendee receives a unique QR-based digital entry pass that can be downloaded and presented at the event.

3. **QR-Based Check-In:** Event organizers scan the attendee's QR code or manually enter their pass ID to verify registration.

4. **Duplicate Check-In Prevention:** The system verifies whether a pass has already been used. Previously checked-in attendees are flagged, preventing duplicate attendance records.

5. **Real-Time Attendance Dashboard:** Organizers can monitor total registrations, successful check-ins, pending attendees, and attendance percentages through a centralized dashboard.

6. **Attendee Management:** Organizers can search, filter, and manage attendee records and export attendance data for reporting.



###  Key Benefits

-  Faster and smoother event entry
-  Unique QR-based attendee verification
-  Prevention of duplicate check-ins
-  Centralized attendance tracking
-  Mobile-friendly QR scanning
-  Reduced manual effort and human errors
-  Paperless event management


###  Our Vision

GatePass aims to make event management smarter, faster, and more accessible by providing a simple, secure, and scalable digital check-in solution for college events, hackathons, workshops, seminars, and conferences.

###  Technology Stack

- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend & Database:** Supabase (PostgreSQL)
- **Authentication:** Supabase Auth
- **QR Code Generation:** qrcode.react
- **QR Code Scanning:** html5-qrcode
- **Deployment:** Vercel
